## Goto Anything Navigation

The heart of <a href="#">download sublime text for mac</a> is Goto Anything — open files and jump to
symbols, lines or words with only a few keystrokes. Triggered with ⌘P, it turns navigation into typing.

- **Open by fuzzy name** — type part of a file name to open it instantly, no folder digging required.
- **Jump to symbols** — type `@` to leap to a function, class or definition inside the current file.
- **Search within a file** — type `#` to find text, or `:` to go straight to a specific line number.
- **Combine shortcuts** — `tp@rf` can take you to a function `read_file` inside `text_parser.py`, and `tp:100` jumps to line 100 of the same file.

Because <a href="#">sublime text mac download</a> makes navigation this fast, you spend your time editing
rather than hunting. Once Goto Anything is in your fingers, moving through a large codebase feels closer
to thinking out loud than to clicking through menus and tabs.

## Multiple Selections

A defining feature of <a href="#">sublime text for mac</a> is multiple selections — make ten changes at
the same time instead of one change ten times. It is one of the biggest everyday time savers in the app.

- **Split into lines** — press ⇧⌘L to break a selection into one caret per line and edit them together.
- **Select next occurrence** — press ⌘D to add the next match of the current word to your selection.
- **Rename with ease** — change a variable everywhere it appears interactively, watching every edit at once.
- **Column selection** — use the mouse for block edits across many rows when you need precise columns.

This interactive, see-it-live approach makes bulk edits fast and safe, which is a big part of why the
<a href="#">text editor mac</a> crowd keeps Sublime Text within arm's reach for refactoring and cleanup.
